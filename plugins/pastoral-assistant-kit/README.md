## 설치 방법

### Claude 웹/데스크톱 (수강생 대부분 여기)

1. 왼쪽 사이드바에서 **Customize** 메뉴를 엽니다
2. **Plugins** 탭으로 이동합니다
3. **Personal plugins** 옆의 **＋** 버튼을 누릅니다
4. 전달받은 `pastoral-assistant-kit.zip` 파일을 업로드합니다

### Claude Code (터미널)

```bash
/plugin marketplace add <배포받은 저장소 주소>
/plugin install pastoral-assistant-kit@spark-pastoral
```

## 처음 한 번만 — 내 문체 설정하기

설교 스킬은 **첫 사용 때 목사님의 설교 문체부터 여쭙습니다.** 아무 문체나 뒤집어씌우지 않기 위해서입니다.
세 가지 방법 중 편한 것을 고르시면 됩니다.

| 방법 | 걸리는 시간 | 정확도 |
|---|---|---|
| **A. 기존 설교 분석** — 지난 설교 원고 2~3편 업로드 | 약 5분 | 가장 정확 |
| **B. 질문 여덟 개** — 구조·문장·청중·원어 등에 답하기 | 약 2분 | 좋음 |
| **C. 프리셋 선택** — 준비된 세 유형 중 가까운 것 고르기 | 즉시 | 쓰면서 다듬기 |

끝나면 Claude가 **문체 프로필 카드**를 만들어 줍니다. 이것을 복사해 두셨다가

- 다음 대화 첫머리에 붙여넣거나
- Claude 설정 → **사용자 설정**에 넣어 두시면 (권장) 매번 붙여넣지 않아도 됩니다.

원고를 받아 보시고 "이 표현은 내 스타일이 아니다"라고 말씀하시면 프로필이 그 자리에서 수정됩니다.
쓰실수록 목사님 목소리에 가까워집니다.

> 프로필 양식은 플러그인 안의
> `skills/pastor-sermon-assistant/assets/style-profile-template.md` 에도 들어 있습니다.
> 강의 시간에 미리 채워 오시게 하면 첫날부터 바로 쓰실 수 있습니다.

## 쓰는 법

설치가 끝나면 대화창에서 그냥 **한국어로 말하면 됩니다.** Claude가 알아서 맞는 스킬을 고릅니다.

> "이번 주 주일 설교문 정리해줘"
> "12월 25일 QT 만들어줘, 본문은 눅 2:1-20"
> "권사님 가정심방 예배 순서 필요해"

목록에서 직접 고르려면 대화창에 **`/`** 를 입력하거나 **＋** 버튼을 누르세요.
플러그인으로 설치된 스킬은 `/pastoral-assistant-kit:qt-companion` 처럼 앞에 플러그인 이름이 붙습니다.

## 알아두실 점

- **유료 플랜(Pro / Max / Team / Enterprise)에서 동작합니다.**
- 설교 스킬은 목사님 문체를 학습해 씁니다. 칼럼·논단·교재 스킬은 제작자의 문체와 관점이 기본값이니, 각자 현장에 맞게 조정해 쓰시길 권합니다.
- AI가 만든 원고는 **초안**입니다. 강단에 서기 전 반드시 본문 주해와 인용 성구를 직접 확인하십시오.
- 스킬 파일은 모두 일반 텍스트(Markdown)입니다. 열어서 직접 고쳐 쓰셔도 됩니다.
