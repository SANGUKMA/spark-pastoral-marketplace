# 한국교회 절기 캘린더와 배치 규칙

## 고정 절기 (날짜가 정해진 것)

| 시기 | 절기 | 성격 |
|---|---|---|
| 1월 1일 | 신년 | 새 출발, 결단 |
| 5월 첫 주일 | 어린이주일 | 다음세대 |
| 5월 둘째 주일 | 어버이주일 | 가정 |
| 5월 셋째 주일 | 스승의 주일 (교회학교 교사) | 감사 |
| 7월 첫 주일 전후 | 맥추감사주일 | 상반기 결산 감사 |
| 10월 마지막 주일 | 종교개혁주일 | 말씀·개혁 |
| 11월 셋째 주일 전후 | 추수감사주일 | 감사 |
| 12월 25일 | 성탄절 | 성육신 |
| 12월 31일 | 송구영신 | 결산, 새해 결단 |

*교단과 교회마다 날짜가 다를 수 있으므로 목회자에게 확인한다.*

## 이동 절기 (해마다 날짜가 바뀌는 것)

부활절을 기준으로 계산한다. **연도가 정해지면 반드시 실제 날짜를 확인한 뒤 배정한다.**

| 절기 | 계산 기준 |
|---|---|
| 재의 수요일 (사순절 시작) | 부활절 46일 전 |
| 사순절 | 재의 수요일 ~ 부활 전야, 약 6주 |
| 종려주일 | 부활절 1주 전 |
| 고난주간 | 종려주일 다음 월요일 ~ 토요일 |
| 성금요일 | 부활절 2일 전 |
| 부활주일 | 춘분 후 첫 보름 다음 주일 |
| 성령강림주일 | 부활절 50일 후 |
| 삼위일체주일 | 성령강림주일 1주 후 |
| 대림절 | 성탄절 전 4주간 |

부활절이 3월 하순이면 사순절이 2월에 시작하고, 4월 하순이면 사순절이 3월 내내 이어진다. **연도에 따라 1분기 구성이 크게 달라지므로 반드시 먼저 확인한다.**

## 교회 자체 일정

목회계획서에서 가져와 함께 배치한다.

- 신년 특별 새벽기도회 (보통 1월 첫 주간)
- 사순절 특별 새벽기도회
- 봄·가을 심방 기간
- 여름 수련회 (교회학교 7~8월, 청년부 8월)
- 총동원 주일 / 전도 축제
- 임직식·직분자 훈련
- 선교주일 / 선교 헌신예배
- 창립 기념 주일
- 제직 수련회, 당회 수련회

이 기간에는 **행사를 지지하는 본문**을 배치한다. 수련회 주간에 무관한 강해를 이어 가면 두 흐름이 따로 논다.

## 월별 배치 참고

| 월 | 주로 배치되는 것 | 주의 |
|---|---|---|
| 1월 | 신년, 특별새벽기도 | 결단 주제가 몰린다. 2월에 숨 쉴 공간을 둔다 |
| 2월 | 사순절 시작 가능 | 부활절 날짜 확인 필수 |
| 3월 | 사순절, 새 학기 | 다음세대 사역 시작과 겹친다 |
| 4월 | 고난주간·부활절 | 1년의 정점. 앞뒤 2주를 비워 집중시킨다 |
| 5월 | 가정의 달 | 어린이·어버이·스승 주일이 연달아 온다 |
| 6월 | 성령강림, 상반기 정리 | 비교적 여유가 있어 강해에 적합 |
| 7월 | 맥추감사, 수련회 준비 | 휴가 시작으로 출석이 흔들린다 |
| 8월 | 수련회, 휴가철 | 출석 최저 시기. 무거운 주제를 피한다 |
| 9월 | 새 학기, 사역 재개 | 재결단 주제가 잘 맞는다 |
| 10월 | 종교개혁주일, 총동원 | 말씀·전도 주제 |
| 11월 | 추수감사, 임직식 | 감사와 헌신 |
| 12월 | 대림·성탄·송구영신 | 전반은 대림, 후반은 결산으로 나눈다 |

---

## 배치 규칙

**부활절 앞뒤를 비워 둔다.** 고난주간과 부활주일은 그 자체로 강력하다. 그 주간에 다른 강해를 겹치면 둘 다 약해진다.

**8월을 과소평가하지 않는다.** 출석이 가장 낮은 달이지만 그래서 오히려 남은 성도를 위한 목양 본문이 필요하다. 시편이 잘 맞는다.

**12월을 한 달로 다루지 않는다.** 대림절과 송구영신은 성격이 다르다. 전반 2주는 기다림, 후반 2주는 성육신과 결산으로 나눈다.

**5월은 주제가 이미 정해져 있다.** 어린이·어버이·스승 주일이 연달아 오므로 별도 주제를 억지로 넣지 않는다. 가정과 관계를 그대로 월 주제로 삼는 편이 자연스럽다.

**연속성이 끊기는 지점을 미리 안다.** 수련회, 총동원 주일, 임직식은 강해의 흐름을 끊는다. 그 주간은 독립 본문으로 두고, 다음 주에 흐름을 다시 잇는다.

---

## 절기 확인 절차

계획 수립을 시작하면 가장 먼저 한다.

1. 대상 연도의 **부활절 날짜**를 확인한다
2. 부활절에서 역산해 재의 수요일, 종려주일, 고난주간, 성령강림주일을 확정한다
3. 대림절 시작일(성탄 전 4주)을 확정한다
4. 목회계획서에서 교회 자체 일정을 가져온다
5. 위 일정을 먼저 캘린더에 고정한 뒤, 남은 날짜에 주제를 채운다

절기를 나중에 끼워 넣으면 반드시 충돌한다. **절기가 먼저, 주제가 나중이다.**
