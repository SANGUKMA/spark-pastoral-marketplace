# 주제 설계 가이드

## 연간 주제의 조건

좋은 연간 주제는 다음을 만족한다.

- **한 문장으로 말할 수 있다.** 설명이 필요하면 주제가 아니라 강령이다.
- **사계절을 견딘다.** 3월에도 11월에도 말이 되어야 한다.
- **성도가 자기 자리에서 적용할 수 있다.** 추상 명사만 있으면 적용이 안 된다.
- **뿌리 본문이 있다.** 주제를 지탱하는 구절 하나가 분명해야 한다.

**약한 주제의 예**
- "은혜" — 너무 넓어 무엇이든 들어간다. 방향이 없다.
- "2027 비전 성취의 해" — 표어이지 말씀 주제가 아니다.

**작동하는 주제의 예**
- "다시, 말씀 앞에" (딤후 3:16–17)
- "함께 세우는 집" (엡 2:19–22)
- "보내심을 받은 자로" (요 20:21)

## 분기 흐름 유형

연간 주제를 네 국면으로 나눌 때 자주 쓰이는 구조들이다. 그대로 쓰기보다 교회 상황에 맞게 변형한다.

### 유형 A. 구원 서정형

```
1분기 부르심  →  2분기 자라감  →  3분기 섬김  →  4분기 보내심
```
신앙의 성장 단계를 그대로 따라간다. 새신자가 많은 교회, 양육 체계를 세우는 해에 적합하다.

### 유형 B. 관계 확장형

```
1분기 하나님과  →  2분기 나 자신과  →  3분기 공동체와  →  4분기 세상과
```
동심원이 넓어지는 구조다. 이해하기 쉽고 적용점이 분명하다. 소그룹 사역과 잘 맞는다.

### 유형 C. 교회력 순응형

```
1분기 사순·부활  →  2분기 성령·교회  →  3분기 성장·훈련  →  4분기 대림·성탄
```
절기가 주제를 결정한다. 절기를 중시하는 교회, 예배 갱신을 목표로 하는 해에 적합하다.

### 유형 D. 회복 서사형

```
1분기 직면  →  2분기 회개  →  3분기 회복  →  4분기 재건
```
어려움을 지난 교회, 분열이나 침체를 회복하는 해에 적합하다. 1분기가 무거우므로 목양적 배려가 필요하다.

### 유형 E. 성경 통독형

```
1분기 율법  →  2분기 역사·지혜  →  3분기 예언  →  4분기 신약
```
정경 순서를 따라간다. 성경 전체를 훑는 것이 목표인 해에 적합하다. 다만 주제 통일성은 약해진다.

## 흐름 점검 질문

분기 주제를 확정하기 전에 스스로 물어야 한다.

1. 1분기와 4분기를 나란히 놓았을 때, 성도가 이동한 거리가 보이는가?
2. 각 분기를 다른 분기로 바꿔 넣어도 말이 되는가? (된다면 흐름이 아니라 나열이다)
3. 가장 무거운 분기는 어디인가? 그 앞뒤에 숨 쉴 공간이 있는가?
4. 절기와 충돌하는 분기는 없는가?

## 월별 주제 세분 원칙

한 분기(3개월)를 나눌 때 쓰는 방식들이다.

**전개형** — 분기 주제를 시간 순으로 푼다.
> 2분기 '자라감' → 4월 말씀으로 / 5월 기도로 / 6월 공동체 안에서

**측면형** — 분기 주제의 여러 면을 각각 다룬다.
> 3분기 '섬김' → 7월 가정에서 / 8월 교회에서 / 9월 이웃에게

**심화형** — 같은 주제를 점점 깊이 들어간다.
> 1분기 '부르심' → 1월 부르시는 하나님 / 2월 응답하는 나 / 3월 순종의 대가

**혼합형** — 절기가 낀 달만 절기 주제, 나머지는 전개형.
실제로 가장 많이 쓰인다. 3월(사순), 5월(가정), 12월(성탄)은 절기가 주제를 가져간다.

## 목회계획서와의 정렬

`church-annual-plan`으로 만든 목회계획서가 있으면 다음을 대조한다.

| 목회계획서 항목 | 말씀계획 반영 |
|---|---|
| 금년 표어 | 연간 주제로 직결 |
| 3대 중점 과제 | 세 개 분기에 하나씩 배분 |
| 부서별 KPI | 해당 월 주제의 적용 항목에 연결 |
| 주요 행사 일정 | 그 주간 본문을 행사와 정렬 |
| 리스크·돌봄 항목 | 소진이 예상되는 시기에 위로 본문 배치 |

**정렬 확인 표를 만들어 목회자에게 보여 드린다.** 표어와 연간 주제가 겉돌면 연말에 두 문서를 다시 맞춰야 한다.

## 흔한 실수

**분기 주제가 너무 비슷하다.** '사랑 / 은혜 / 긍휼 / 자비'는 네 개가 아니라 하나다.

**월 주제가 12개가 아니다.** 8월 휴가철이나 12월 연말을 비워 두면 그 달 QT가 표류한다. 12개를 모두 채운다.

**주제가 본문보다 먼저 굳는다.** 주제를 확정한 뒤 본문을 찾다 보면 억지 연결이 생긴다. 주제를 정할 때 이미 어떤 본문 뭉치를 쓸지 대략 잡아 둔다.

**작년과 같다.** 3년 이상 사역한 교회라면 작년·재작년 주제를 확인하고 반복을 피한다.
