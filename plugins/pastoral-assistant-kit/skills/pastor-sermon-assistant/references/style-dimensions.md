# 설교 문체 여덟 축 — 판별 기준

기존 설교 원고를 분석해 프로필을 만들 때 사용하는 기준표입니다.
각 축마다 "무엇을 보고 판단하는가"를 적었습니다. 추측하지 말고 원고에서 근거를 찾으십시오.

---

## 1축 · 구조

| 유형 | 원고에서 나타나는 신호 |
|---|---|
| 3대지형 | 대지 번호나 소제목이 셋. 각 대지가 독립된 주제어를 가짐 |
| 순차 강해형 | 본문 절 순서를 그대로 따라감 (12절 → 13-14절 → 15절) |
| 단일 주제형 | 대지 구분 없이 하나의 명제를 여러 각도로 반복 심화 |
| 이야기형 | 서사가 이어지며 중간에 전환점이 있고 끝에서 의미가 드러남 |

**판별 팁**: 소제목이 없어도 문단 첫 문장이 "첫째", "그리고 두 번째로"로 시작하면 대지형입니다.

## 2축 · 문장 호흡

| 유형 | 신호 |
|---|---|
| 장문 흐름형 | 평균 60자 이상. 접속어로 절을 이어 논리를 쌓음 |
| 단문 타격형 | 평균 30자 이하. 마침표가 잦고 한 문장 한 메시지 |
| 혼합형 | 설명은 길게, 결정적 순간에 짧게 끊음 |

**판별 팁**: 임의의 세 문단을 골라 문장 수와 글자 수를 세어 평균을 내십시오.

## 3축 · 청중

| 유형 | 신호 |
|---|---|
| 청년 | 취업·이직·연애·자취·SNS 소재. 호칭이 "여러분" |
| 장년·시니어 | 자녀·건강·노년·평생 신앙 소재. 호칭이 "성도 여러분" |
| 전 연령 혼합 | 특정 세대 소재 없이 보편적 상황 위주 |
| 가족·어린이 포함 | 짧은 문장, 쉬운 어휘, 질문형 상호작용 |

## 4축 · 원어 사용

| 유형 | 신호 |
|---|---|
| 적극 | 편당 3회 이상. 원어 표기 + 발음 + 의미 설명 |
| 절제 | 편당 1-2회. 핵심 단어에만 |
| 미사용 | 원어 대신 "이 말은 원래 ~라는 뜻입니다" 식 우회 설명 |

**표기 방식도 함께 기록하십시오**: 원어만 / 원어+한글 발음 / 한글 발음만

## 5축 · 신학 전통

| 유형 | 신호 |
|---|---|
| 개혁주의 | 은혜 우선, 그리스도 중심 해석, 언약·구속사, 칼빈·바빙크·켈러 인용 |
| 웨슬리안·성결 | 성결과 온전한 사랑, 성화의 과정, 웨슬리 인용 |
| 오순절 | 성령의 역사와 체험, 은사, 능력 |
| 복음주의 일반 | 특정 전통 색채 없이 성경 본문과 실천 중심 |

**판별 팁**: 인간의 노력을 강조하는가, 하나님의 주도를 강조하는가를 보면 대체로 갈립니다.

## 6축 · 예화 성향

| 유형 | 신호 |
|---|---|
| 가정·일상 | 자녀·부부·이웃 관계 |
| 사회·시사·통계 | 뉴스, 조사 수치, 사회 현상 |
| 역사·인물 | 신앙 위인, 역사적 사건 |
| 목회 현장 | "제가 심방을 갔는데" 류의 직접 경험 |
| 자기 고백 | 설교자 자신의 실패와 씨름 |

복수로 나타나는 것이 보통입니다. **비중 순으로** 기록하십시오.

## 7축 · 결론 방식

| 유형 | 신호 |
|---|---|
| 결단 촉구 | "오늘 결단하십시오", 명령형 마무리 |
| 위로·확신 | "하나님이 함께하십니다", 약속 선포 |
| 교훈 제시 | 핵심 정리 나열로 마무리 |
| 예배로 연결 | 찬양·기도·성찬으로 자연스럽게 이어감 |

## 8축 · 분량과 시간

한국어 설교는 대략 **분당 300~350자**입니다.

| 시간 | 원고 분량 |
|---|---|
| 20분 | 약 6,000~7,000자 |
| 30분 | 약 9,000~10,500자 |
| 40분 | 약 12,000~14,000자 |

원고를 그대로 읽지 않고 확장해 말하는 설교자라면 이보다 적게 잡습니다.
사용자에게 "원고를 그대로 읽으십니까, 개요만 보고 확장하십니까"를 물어 조정하십시오.

## 여덟 축 외에 반드시 기록할 것

- **호칭**: 청중을 부르는 정확한 표현
- **입버릇**: 반복되는 연결어와 전환 문구 (3개 이상 수집)
- **강조 방식**: 볼드 / 반복 / 수사적 질문 / 침묵 지시
- **피하는 것**: 사용자가 싫어한다고 밝힌 표현이나 소재
