## 항목 2. 해결 방안
*어떻게 해결할 것인가*

|---|---|---|---|---|
| | | | | |

- ❌ "더 좋다", "은혜가 된다", "부흥할 것이다"

## 항목 4. 성장 목표
*3년 내 어느 정도 성장하는가*

### 용어 치환 원칙

창업 사업계획서 용어를 교회 언어로 바꾼다. 개념은 유지하고 표현만 순화한다.

| 원 용어 | 계획서 표기 |
|---|---|
| 유효시장(SAM) | 전도 가능 권역 |
| 목표시장(SOM) | 접촉 가능 대상층 |
| 시장 점유율 | 지역 내 사역 도달률 |
| 고객 | 성도 / 지역 주민 |
| 매출 | 헌금 / 출석 규모 |

### 작성 순서

1. 사업 또는 부서의 **범위와 규모**를 정한다.
2. **전도 가능 권역**을 설정한다.
   예: 교회 반경 3km, 행정동 4개, 총 인구 8.2만 명
3. 그중 **접촉 가능 대상층**을 추정한다.
   예: 30~50대 유자녀 가구 1.1만 세대
4. **향후 3년 성장률**을 출석자 수와 헌금 규모 기준으로 추정한다.

과다한 목표를 잡지 않는다. **현재 진입해 있거나 진입 가능한 범위**를 기준으로 한다. 부풀린 목표는 2년차에 반드시 부담으로 돌아온다.

### 활용 가능한 공개 통계 출처

- 행정안전부 주민등록 인구통계 — 읍면동 단위 연령별 인구
- 통계청 KOSIS — 가구 구성, 지역 통계
- 학교알리미 / 시도교육청 — 학령 인구, 다음세대 사역 근거
- 목회데이터연구소 리포트
- 한국기독교목회자협의회 조사
- 소속 교단 총회 통계 — 교세 추이 비교

출처는 반드시 **기관명 + 자료명 + 기준 연월**을 병기한다.
예: `행정안전부 주민등록 인구통계, 2026년 6월 기준`

## 항목 5. 벤치마킹 교회 분석

'유사교회 경쟁 분석'을 **벤치마킹**으로 재프레이밍한 항목이다. 인근 교회를 경쟁자로 규정하지 않는다. 그런 문서가 외부로 나가면 교회에 해가 된다.

**분석 대상**: 비슷한 규모·지역·사역 방향을 가진 교회 최대 3곳

**분석표**

| 구분 | 교회 A | 교회 B | 교회 C |
|---|---|---|---|
| 규모·지역 | | | |
| 주목할 사역 | | | |
| 공개된 성과 | | | |
| 우리와 다른 조건 | | | |
| 그대로 적용 가능 | | | |
| 조정 후 적용 | | | |
| 적용 불가 | | | |

마지막에 **우리 교회만의 차별 지점**을 서술한다.

**근거 제한**
공개 자료(교회 홈페이지, 언론 보도, 교단지, 사역 보고서)로만 작성한다. 추측성 평가와 비방은 어떤 경우에도 쓰지 않는다.

유사 사례를 찾지 못하면, 자체적으로 문제를 해결할 방식을 구체적 예시와 함께 제시한다.

**6-2. 지역교회 전략**

- **신뢰성** — 교회 브랜드 인지도 확보 방안
- **전도 전략** — 세 갈래로 나누어 작성
  1. 모바일 전도 전략 (카카오 채널, 문자, 단톡방, 숏폼)
  2. 온라인 전도 전략 (홈페이지, 유튜브, 검색 노출, 온라인 예배)
  3. 오프라인 전도 전략 (지역 행사, 관계 전도, 초청 주일)

**6-3. 거점교회 전략**
광역 단위 확장을 계획하는 경우에만 작성한다. 해당 없으면 "해당 없음"으로 명시한다.

**6-4. 3개년 추진 계획**

```
1년차 : 성도 훈련과 교재 정비, 전도 전략 실험
2년차 : 지역에 맞는 전도 전략 확정, 리더 세우기
3년차 : 확장형 조직 구조 구축, 훈련 체계 고도화
```

각 연차마다 주요 이정표(프로그램 추가, 선교, 지역사회 연계 등)를 함께 기재한다.

## KPI 및 SMART 가이드

**SMART** — 구체적(Specific) · 측정 가능(Measurable) · 달성 가능(Achievable) · 관련성(Relevant) · 기한(Time-bound)

KPI는 반드시 네 요소를 갖춘다: `지표명 / 기준선 / 목표값 / 측정 주기`

**작성 예시**
- "새가족 정착률을 2026년 12월까지 57% → 75%로 향상 (분기별 측정)"
- "청년부 소그룹 12개 → 18개 확대, 리더 24명 훈련 완료 (7~10월)"

**나쁜 예시**
- "새가족을 잘 정착시킨다" — 측정 불가
- "청년부를 부흥시킨다" — 기준선도 목표값도 없음
