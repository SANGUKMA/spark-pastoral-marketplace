# 성경적 근거 매핑 규칙

## 기본 원칙

모든 주요 목표·전략·프로그램 항목에 **최소 1구절**을 매핑한다. 권장 1~3구절.

**표기 형식**
```
요 4:23–24(개역개정)
→ 아버지께서 영과 진리로 예배하는 자를 찾으신다. 예배 갱신을 올해 최우선 과제로 두는 근거가 여기에 있다.
```

구절만 나열하고 설명을 붙이지 않으면 장식이 된다. 반드시 **1~2문장의 연결 설명**을 함께 쓴다. 왜 이 구절이 이 목표를 지지하는지 밝힌다.

## 선택 원칙

**문맥에 충실할 것.** 구절이 원래 무엇을 말하는지 확인하고 인용한다. 문맥과 무관한 구절을 목표에 억지로 붙이는 것이 증거구절 남용(proof-texting)이다. 당회에 신학을 아는 분이 계시면 반드시 지적받는다.

**주제에 적합할 것.** 아래 매핑표는 출발점이지 정답이 아니다. 계획의 실제 내용에 더 맞는 구절이 있으면 그것을 쓴다.

**교단 신학에 반하지 않을 것.** 기본은 개혁주의 관점이다. 번영신학적 해석(헌금하면 물질로 갚아 주신다는 식)으로 재정 항목을 뒷받침하지 않는다.

**번역본.** 기본은 개역개정. 사용자가 다른 번역을 요청하면 그에 맞춘다.

## 항목별 매핑 예시

**항목 1 (배경 및 필요성)**
문제 진단에는 교회의 본질을 상기시키는 구절이 어울린다. 행 2:42–47은 초대교회의 모습을 통해 지금 무엇이 결핍되었는지 비추어 준다.

**항목 4 (성장 목표)**
수치 목표를 세우는 대목이다. 성장을 사람의 성취로 읽지 않도록 고전 3:6("나는 심었고 아볼로는 물을 주었으되 오직 하나님께서 자라나게 하셨나니")을 함께 두면 균형이 잡힌다.

**항목 6 (전도 전략)**
행 1:8은 지역에서 시작해 확장되는 구조 자체를 보여 준다. 지역교회 → 거점교회 전략의 순서와 잘 맞는다.

**항목 7 (예산 계획)**
고후 9:6–8은 자원하는 마음의 연보를 말한다. 강제 모금의 근거로 쓰지 않는다. 청지기 직분의 책임을 강조하려면 눅 16:10–11이 더 적합할 때가 있다.

**항목 8 (안전·아동보호)**
마 18:6, 마 19:14는 아동보호 정책의 신학적 근거가 된다. 안전 규정을 행정 절차가 아니라 목회적 책임으로 읽게 해 준다.

## 금지 사항

- 구절만 나열하고 설명을 생략하는 것
- 한 항목에 4구절 이상 붙이는 것 (희석된다)
- 문맥과 무관한 구절을 목표에 끼워 맞추는 것
- 번영신학적 해석으로 재정 목표를 정당화하는 것
- 다른 교회를 비판하는 근거로 성경을 인용하는 것
