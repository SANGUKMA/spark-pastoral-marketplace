# 칼럼 작성 템플릿

## 기본 구조

```
[제목]
[부제]

[서론]
21세기에 들어 우리는... [시대적 맥락 제시]
이러한 변화는... [문제의식 명확화]
본 에세이는... [칼럼의 목적과 방향]

1. [섹션 1 제목: 현상 분석]
변화하는 환경: [현재 상황 설명]
[통계 데이터 제시] 예를 들어 2024년 조사에서...¹
[구체적 사례 소개]

2. [섹션 2 제목: 가능성]
[기술/이슈]가 열어주는 새로운 가능성: [긍정적 측면]
[구체적 활용 사례] 예를 들어...
[선교적/목회적 의미]

3. [섹션 3 제목: 한계]
본질적 한계: [한계 분석]
[신학적·윤리적 고려사항]
[경계해야 할 지점]

4. [섹션 4 제목: 대안]
상호보완적 협력 모델: [통합적 접근]
[구체적 방안 제시]
윤리적 원칙의 수립: [실천 원칙]

5. [섹션 5 제목: 전망]
미래를 향한 전망과 제언: [향후 전망]
[교회와 목회자를 위한 제안]
[준비 방안]

결론: [마무리 제목]
우리는... [핵심 메시지 재강조]

[역사적 사례로 희망 제시]

참고문헌
1. [저자]. "[제목]." [출처] ([날짜])
2. ...
```

## 문단 작성 예시

### 서론 문단 패턴

**패턴 1: 현상 제시형**
```
21세기에 들어 우리는 [변화의 양상]을 목격하고 있다. [기술/현상]의 확산은 단순한 [표면적 변화]를 넘어 [근본적 변화]를 가져왔다. 이러한 변화는 [대상 영역]에도 심대한 영향을 미치고 있다.
```

**패턴 2: 문제 제기형**
```
[대상 집단]은 이제 [도전 과제] 앞에 서 있다. 과거 [과거 방식]이 주효했던 시기와 달리, 이제 [새로운 패러다임]의 전환이 요구된다.
```

### 본론 문단 패턴

**패턴 1: 데이터 기반 분석**
```
[주제 문장]. 예를 들어 2024년 조사에서 [연령대]의 [퍼센트]는 [현상]으로 분류했는데, [비교 대상]에서 같은 응답을 한 비율은 [퍼센트]에 불과했다.¹ [해석 및 함의]
```

**패턴 2: 사례 제시형**
```
[기술/방법]은 [영역]에 혁신적인 변화를 가져올 수 있다. 예를 들어 [구체적 상황]이라면, [기술/방법]은 [구체적 방안]을 제시할 수 있다. 또한 [추가 활용 방안]도 가능하다.
```

**패턴 3: 한계 지적형**
```
[기술/방법]이 아무리 발전해도 결코 넘을 수 없는 한계가 있다. 그것은 [본질적 한계]이다. [구체적 설명]. [대조 사례]. 이러한 것들은 [기술/방법]이 흉내낼 수 없는 [인간/신앙]만의 영역이다.
```

### 결론 문단 패턴

**패턴 1: 균형 강조형**
```
우리의 과제는 명확하다. [기술/방법]의 장점을 최대한 활용하되, [본질적 가치]를 더욱 소중히 여기는 것이다. [기술]이 [역할]이 된다면, [인간/신앙]은 [역할]이어야 한다.
```

**패턴 2: 역사적 희망형**
```
역사를 돌아보면 [과거 사례]는 [긍정적 결과]를 가져왔다. 마찬가지로 [현재 기술/방법]도 [목적]을 위한 도구로 쓰일 수 있다. 중요한 것은 [본질]이다.
```

## 각주 작성 가이드

### 기본 형식
```
본문: ...보고되었다.¹
각주: 1. [저자/출처]. "[제목]." [매체/기관] ([날짜])
```

### 온라인 자료
```
1. 김진영. "교회 출석 3명 중 1명 이상 '교회에서 외로움 느껴'." 기독일보 (2023년 12월 12일)
```

### 학술 자료
```
2. 목회데이터연구소. "교회 출석 청년의 삶과 신앙" (목회데이터 2023년 조사)
```

### 웹사이트
```
3. OpenAI. "Whisper를 소개합니다." (OpenAI 공식 블로그, 2022년 9월 21일)
```

## 문체 가이드

### 권장 표현
- "~이다", "~한다" (평서형 종결)
- "예를 들어", "가령", "실제로" (예시 제시)
- "그러나", "한편", "동시에" (전환)
- "이는", "이러한", "이처럼" (지시)
- "요컨대", "결국", "그러므로" (결론)

### 지양 표현
- 과도한 비유: "마치 ~처럼", "~인 양"
- 감성적 수사: "가슴 뛰는", "설레는"
- 모호한 표현: "어쩌면", "아마도"
- 구어체: "~거든요", "~잖아요"

## 체크리스트

### 작성 전
- [ ] 주제가 명확한가?
- [ ] 필요한 통계 자료를 확보했는가?
- [ ] 신학적 근거를 준비했는가?
- [ ] 대상 독자를 고려했는가?

### 작성 중
- [ ] 각 섹션의 제목이 명확한가?
- [ ] 통계 데이터에 출처를 표기했는가?
- [ ] 장점과 한계를 균형있게 다루었는가?
- [ ] 구체적인 실천 방안을 제시했는가?

### 작성 후
- [ ] 전체 논리 흐름이 자연스러운가?
- [ ] 각주와 참고문헌이 정확한가?
- [ ] 분량이 적정한가? (5,000-6,000자)
- [ ] 신학적 균형을 유지했는가?
- [ ] 실천 가능한 제안을 담았는가?
