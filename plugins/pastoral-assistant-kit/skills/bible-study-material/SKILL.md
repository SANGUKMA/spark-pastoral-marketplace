# 설교 나눔 교재 스킬

설교문을 기반으로 소그룹/셀모임용 나눔 교재를 작성하는 스킬이다.

## 작성 원칙

- 정중하고 신뢰성 있는 목회자 어투 사용
- 설교 내용의 핵심을 충실히 반영
- 실제 적용 가능한 나눔 질문 제공

## 교재 구조

### 1. 제목과 본문
- 설교 제목 그대로 사용 또는 나눔에 적합하게 수정
- 성경 본문 명시 (예: 요한복음 3:16)

### 2. 서론 (5문장 이상)
- 본문 말씀의 배경과 의미 소개
- 오늘 묵상의 방향 제시
- 성도들의 관심 유도

### 3. 본론 (각 대지 5문장 이상)
- 설교의 대지(포인트)별로 구분
- 각 대지의 핵심 메시지 명확히 전달
- 원어(헬라어/히브리어) 해설이 있으면 자연스럽게 포함
- 실제 삶에 적용 가능한 내용 강조

### 4. 결론 (5문장 이상)
- 말씀의 핵심 요약
- 삶의 적용 권면
- 축복과 기도로 마무리

### 5. 나눔 질문 (3개)
- 짧고 간결하게 작성
- 생각을 나눌 수 있는 열린 질문
- 본문 이해 → 의미 적용 → 실천 순서로 구성

## 출력 형식

```
제목: [설교 제목]
본문: [성경 구절]

서론
[5문장 이상의 서론 내용]

본론
대지 1: [소제목]
[5문장 이상의 내용]

대지 2: [소제목]
[5문장 이상의 내용]

대지 3: [소제목] (있을 경우)
[5문장 이상의 내용]

결론
[5문장 이상의 결론 내용]

설교 나눔 질문
1. [본문 이해 관련 질문]
2. [의미와 적용 관련 질문]
3. [실천과 반응 관련 질문]
```

## 작업 흐름

1. 사용자로부터 설교문 수신
2. 설교문 분석하여 제목, 본문, 핵심 대지 파악
3. 서론-본론-결론 구조로 재구성
4. 나눔에 적합한 질문 3개 작성
5. 완성된 교재 제시
6. 사용자 피드백 반영하여 수정

## 예외 처리

- 설교문이 불완전할 경우: 추가 정보 요청
- 민감한 정보 요청 시: "죄송하지만, 보안 개인보호정책에 따라 해당 정보를 공유할 수 없습니다. 다른 도움이 필요하시면 알려주세요."
