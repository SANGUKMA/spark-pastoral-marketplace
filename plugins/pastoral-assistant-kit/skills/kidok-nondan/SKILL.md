# 기독신문 논단 작성 스킬

기독신문의 [논단] 형식으로, 교단·교회·사회 이슈에 대한 논리적이고 설득력 있는 논평을 작성하는 스킬입니다.

## 논단의 핵심 특징

### 장르적 특성
- **논평/주장형**: 개인 경험담이 아닌 이슈에 대한 논평
- **논리적 설득**: 명확한 주장과 체계적 근거 제시
- **시의성**: 현재 교단/교회/사회의 중요한 이슈 다룸
- **학술적 깊이**: 역사적 사례, 학술서 인용으로 권위 확보

### 대상 독자
- 목회자와 교단 지도자
- 교회 정책 결정자
- 신학적·사회적 이슈에 관심 있는 성도

### [목회칼럼]과의 차이

| 구분 | 목회칼럼 | 논단 |
|------|----------|------|
| 소재 | 개인 경험담 | 교단/사회 이슈 |
| 구조 | 경험-회상-말씀-고백 | 정의-근거-진단-대안 |
| 문체 | 따뜻한, 고백적 | 명료한, 단정적 |
| 근거 | 성경 말씀, 개인 체험 | 학술서, 역사적 사례 |
| 분량 | 1,000-1,500자 | 1,500-2,000자 |

## 논단 구조

### 1. 제목
**주장을 명확히 담은 제목**
- 핵심 메시지를 직접적으로 표현
- 명제형 또는 주장형 문장
- 예: "품격 있는 선택이 품격 있는 총회를 만든다"

**제목 작성 패턴:**
- "[핵심 가치]가 [결과]를 만든다"
- "[문제]를 넘어 [대안]으로"
- "[시대]가 요구하는 [가치]"

### 2. 도입부: 개념 정의 (200-300자)
**핵심 개념의 정의로 시작**
- 사전적 정의 제시
- 역사적/문화적 맥락 설명
- 왜 이 개념이 중요한지 제시

**작성 패턴:**
```
'[핵심 개념]'이란 단어는 사전적으로 '[정의]'로 정의된다.
말하자면, [구체적 설명].
[역사적 맥락에서의 의미].
```

**예시:**
```
'품격'이란 단어는 사전적으로 '사람이 지니고 있는 품위나 인격의 수준'으로 정의된다.
말하자면, 그 사람의 겉모습이 아니라 말과 행동, 태도 속에서 드러나는 됨됨이요, 
삶에서 품어내는 향기다.
```

### 3. 전개부 1: 역사적/학술적 근거 (300-400자)
**권위 있는 근거로 논지 강화**
- 역사적 사례 제시
- 학술서나 전문가 인용
- 구체적 사례로 개념 설명

**근거 제시 패턴:**
```
[학자 이름] 교수는 그의 저서 <책 제목>에서 [내용]이라고 말한다.
[역사적 시대]에 [사례].
이는 [해석/의미]를 보여준다.
```

**소제목 작성:**
- 명제형 문장으로 핵심 주장 표현
- 예: "지도자 태도는 공동체의 기준이다"

### 4. 전개부 2: 원리/보편성 확장 (300-400자)
**보편적 원리로 확장**
- "어느 시대나", "어떤 공동체에서나" 같은 보편화
- 지도자/공동체/제도의 일반 원리 제시
- 성경적 원리나 신앙적 통찰 연결

**확장 패턴:**
```
어느 시대나 [보편적 원리].
특히 [기독교적 맥락에서의 의미].
그러기에 [결론].
```

**소제목 예시:**
- "품격은 단시간에 형성되지 않는다"
- "리더십의 본질은 섬김이다"

### 5. 전개부 3: 현실 진단 (300-400자)
**시의성 있는 이슈 다루기**
- 현재 교단/교회/사회의 구체적 상황
- 문제의식 명확히 제기
- 긴급성과 중요성 강조

**진단 패턴:**
```
[현재 상황 제시].
[구체적 문제점].
이는 [문제의 본질]을 보여준다.
```

**소제목 예시:**
- "총회 앞두고 더 절실해지는 품격"
- "교회 신뢰 회복이 시급하다"

### 6. 전개부 4: 대안 제시 (200-300자)
**구체적이고 실천 가능한 대안**
- "~해야 한다" 당위형 표현
- 실천 주체 명확히 지정
- 단계적 접근 제시

**대안 제시 패턴:**
```
[실천 주체]는 [구체적 행동]을 해야 한다.
특히 [강조할 부분].
[실천의 우선순위].
```

### 7. 결론부: 비전과 호소 (200-300자)
**희망적 비전 제시**
- 역사적 사례와 연결하여 마무리
- 변화의 가능성 제시
- 독자를 향한 호소와 격려

**결론 패턴:**
```
[역사적 사례]처럼, 오늘의 [주체] 역시 [행동]해야 한다.
결국 [핵심 가치]는 [결과]를 가져온다.
우리가 [실천]한다면, [희망적 미래].
```

## 글쓰기 원칙

### 문체와 어조
- **명료한 문장**: 짧고 명확한 서술
- **단정적 어조**: "~이다", "~해야 한다"
- **논리적 연결**: 접속사로 논리 관계 명확히
- **은유 절제**: 직접적 표현 선호

### 근거 제시 방식
1. **학술적 인용**
   - 저자명, 책 제목 명확히 표기
   - 예: "설혜심 교수는 그의 저서 <매너의 역사>에서"

2. **역사적 사례**
   - 시대와 지역 구체적으로 언급
   - 예: "중세 유럽 사회에서", "18세기 영국 신사계급"

3. **성경적 원리**
   - 예수님의 삶과 가르침 인용
   - 신약/구약의 원리 적용

### 논리 전개 패턴

**연역적 구조:**
```
보편적 원리 (정의, 역사적 사례)
    ↓
현재 상황에 적용
    ↓
문제 진단
    ↓
해결책 제시
```

**삼단논법 활용:**
```
대전제: 지도자의 품격이 공동체를 결정한다
소전제: 교단 지도자는 하나님 나라를 대리한다
결론: 교단 지도자는 더 높은 품격이 요구된다
```

### 강조 기법
- **반복**: 핵심 단어를 여러 단락에서 반복
- **대구**: 대비되는 개념을 병렬로 제시
- **예시**: "~처럼, ~도" 구조로 유사성 강조

## 소제목 작성법

### 소제목의 역할
- 각 섹션의 핵심 주장 요약
- 독자의 이해를 돕는 이정표
- 논리적 흐름을 시각적으로 표현

### 소제목 패턴

**1. 명제형**
- "지도자 태도는 공동체의 기준이다"
- "품격은 단시간에 형성되지 않는다"

**2. 질문형**
- "무엇이 진정한 리더십인가"
- "교회가 나아갈 방향은"

**3. 강조형**
- "총회 앞두고 더 절실해지는 품격"
- "지금이야말로 변화할 때"

## 작성 프로세스

### 1단계: 주제와 주장 명확화
- 다룰 이슈 선정
- 핵심 주장을 한 문장으로 정리
- 제목 초안 작성

### 2단계: 근거 자료 수집
- 관련 학술서, 논문 검색
- 역사적 사례 조사
- 성경적 근거 준비

### 3단계: 개요 작성
```
1. 도입: [핵심 개념] 정의
2. 전개1: [역사적 사례] - 소제목
3. 전개2: [보편적 원리] - 소제목
4. 전개3: [현실 진단] - 소제목
5. 전개4: [대안 제시] - 소제목
6. 결론: [비전 제시]
```

### 4단계: 초고 작성
- 개요에 따라 순차적 작성
- 소제목 먼저 쓰고 내용 채우기
- 논리적 연결 확인하며 진행

### 5단계: 퇴고
- 주장의 일관성 점검
- 근거의 타당성 확인
- 불필요한 수식어 삭제
- 문장 간결하게 다듬기

## 분량 가이드

- **전체**: 1,500-2,000자
- **도입부**: 200-300자 (15%)
- **전개부 1-2**: 각 300-400자 (40%)
- **전개부 3-4**: 각 250-350자 (30%)
- **결론부**: 200-300자 (15%)

## 피해야 할 요소

- 지나친 감성적 표현
- 개인적 경험담 중심 서술
- 근거 없는 단정
- 공격적이거나 비판적 어조
- 과도한 수사적 표현

## 강조해야 할 요소

- 논리적 일관성
- 권위 있는 근거
- 구체적 대안
- 균형잡힌 시각
- 건설적 제안

## 참고 사항

### 학술적 인용 방법
```
[저자명] 교수는 그의 저서 <책 제목>에서 [내용]고 말한다.
```
- 저자의 직함 포함 (교수, 박사 등)
- 책 제목은 꺾쇠괄호 사용

### 역사적 사례 제시
```
[시대] [지역]에서 [사례].
이는 [의미/교훈]을 보여준다.
```
- 시대와 장소 구체적으로
- 사례와 현재의 연결고리 명확히

### 성경적 근거 제시
```
예수 그리스도께서는 [행동/가르침].
이는 [적용점]을 보여준다.
```
- 직접 인용보다 의미 전달
- 성경 구절 출처는 필요시만

## 예시 분석

**논단: "품격 있는 선택이 품격 있는 총회를 만든다" (이승호 목사)**

### 전체 구조

```
도입: '품격' 개념 정의 + 중세 유럽 사례
  ↓
소제목 1: "지도자 태도는 공동체의 기준이다"
  → 보편적 원리 + 기독교적 의미
  ↓
소제목 2: "품격은 단시간에 형성되지 않는다"
  → 품격의 형성 과정 + 예수님의 본
  ↓
소제목 3: "총회 앞두고 더 절실해지는 품격"
  → 현재 상황 + 총회 임박
  ↓
소제목 4: "품격 있는 지도자가 세상을 바꾼다"
  → 대안 제시 + 실천 촉구
  ↓
결론: 역사와 연결 + 희망적 비전
```

### 강점 분석

**1. 명확한 개념 정의**
```
'품격'이란 단어는 사전적으로 '사람이 지니고 있는 품위나 
인격의 수준'으로 정의된다.
```
- 사전적 정의로 시작
- 구체적 설명 추가
- 독자와 공통 이해 형성

**2. 권위 있는 근거**
```
설혜심 교수는 그의 저서 <매너의 역사>에서 
중세 프랑스 궁정문화와 18세기 영국 신사계급의 
생활방식을 논하면서...
```
- 학자 인용으로 권위 확보
- 구체적 역사적 사례 제시

**3. 논리적 전개**
```
지도자의 품격 → 공동체 형성
교회 지도자 → 하나님 나라 대리
∴ 더 높은 품격 요구됨
```

**4. 시의성**
```
제110회 교단 총회가 3개월 앞으로 다가왔다.
```
- 구체적 시점 명시
- 긴급성 부여

**5. 실천적 대안**
```
총대들은 지역주의, 동기회, 그 외 아름답지 못한 행위들에 
자유로우며, 성숙하고 품격 있는 총회를 위해 
품격 있는 지도자를 세운다는 스스로의 기준을 세워가자.
```
- 구체적 실천 주체 지정
- 명확한 행동 제시

**6. 순환 구조**
```
도입: 중세 유럽 귀족의 품격
결론: 중세 유럽 귀족처럼, 오늘의 교회 지도자도...
```
- 역사적 사례로 시작하고 마무리
- 일관성과 설득력 강화

### 문체적 특징

**1. 짧고 명확한 문장**
```
품격은 오랜 시간 훈련된 절제력, 일관된 언행, 
성찰된 인격에서 비롯되며, 내면의 신념과 
도덕성이 쌓인 결과물이다.
```

**2. 단정적 어조**
```
지도자의 품격은 공동체의 신뢰 기반이며,
정치와 외교, 교육과 문화, 심지어 신앙의 깊이까지도
그 품격에 의해 결정된다.
```

**3. 대구 활용**
```
지도자의 말은 공동체의 방향이 되고,
태도는 기준이 되며,
품격은 전체 분위기를 형성한다.
```

### 적용 포인트

이 논단에서 배울 수 있는 패턴:

1. **개념 정의로 시작** (공통 이해 형성)
2. **역사적 사례로 권위 확보**
3. **보편적 원리로 확장**
4. **시의성 있는 이슈 연결**
5. **구체적 대안 제시**
6. **희망적 비전으로 마무리**
