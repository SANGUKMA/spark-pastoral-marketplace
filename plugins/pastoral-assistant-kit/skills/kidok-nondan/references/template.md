# 기독신문 논단 작성 템플릿

## 기본 템플릿

```
제목: [주장을 명확히 담은 명제형 제목]

[도입부 - 200-300자]
'[핵심 개념]'이란 단어는 사전적으로 '[정의]'로 정의된다.
말하자면, [구체적 설명].
[역사적/문화적 맥락].

[전개부 1 - 300-400자]
## [명제형 소제목]
[역사적 사례나 학술적 근거].
[저자명] 교수는 그의 저서 <책 제목>에서 [내용]고 말한다.
이는 [해석/의미]를 보여준다.

[전개부 2 - 300-400자]
## [명제형 소제목]
어느 시대나 [보편적 원리].
특히 [기독교적 맥락].
그러기에 [결론].

[전개부 3 - 300-400자]
## [명제형 소제목]
[현재 상황 제시].
[구체적 문제점이나 이슈].
[시의성/긴급성 강조].

[전개부 4 - 250-350자]
## [명제형 소제목]
[실천 주체]는 [구체적 행동]을 해야 한다.
특히 [강조할 부분].
[실천의 우선순위].

[결론부 - 200-300자]
[역사적 사례]처럼, 오늘의 [주체] 역시 [행동]해야 한다.
결국 [핵심 가치]는 [결과]를 가져온다.
우리가 [실천]한다면, [희망적 미래].
```

## 제목 패턴

### 패턴 1: 인과관계형
```
[원인]이 [결과]를 만든다
예: "품격 있는 선택이 품격 있는 총회를 만든다"
예: "섬김의 리더십이 교회를 세운다"
```

### 패턴 2: 대안 제시형
```
[문제]를 넘어 [대안]으로
예: "갈등을 넘어 화해로"
예: "분열을 넘어 일치로"
```

### 패턴 3: 요청형
```
[시대]가 요구하는 [가치]
예: "이 시대가 요구하는 목회자의 품격"
예: "변화의 시대가 요구하는 교회의 본질"
```

### 패턴 4: 질문형
```
진정한 [가치]는 무엇인가
예: "진정한 교회 성장은 무엇인가"
예: "복음적 리더십의 본질은 무엇인가"
```

## 도입부 작성법

### 기본 구조
```
정의 → 설명 → 역사적 맥락 → 중요성
```

### 패턴 1: 사전적 정의로 시작
```
'[개념]'이란 단어는 사전적으로 '[정의]'로 정의된다.
말하자면, [일상적 언어로 재해석].
[비유적 표현].
```

### 패턴 2: 역사적 배경 제시
```
[시대] [지역]에서 [개념]은 [의미]였다.
[구체적 사례].
이는 [현재적 의미]를 시사한다.
```

### 패턴 3: 문제 상황 제기
```
오늘날 [분야]에서 [문제]가 심각하다.
이는 [근본 원인] 때문이다.
[핵심 개념]에 대한 재고가 필요하다.
```

## 소제목별 작성 패턴

### 전개부 1: 역사적/학술적 근거

**소제목 패턴:**
- "[주체]의 [속성]은 [결과]이다"
- 예: "지도자의 태도는 공동체의 기준이다"

**내용 구조:**
```
[역사적 시대와 장소] [사례].
[학자명] 교수는 그의 저서 <책 제목>에서 [내용]고 말한다.
이처럼 [결론].
```

**예시:**
```
## 지도자 태도는 공동체의 기준이다

어느 시대나 지도자의 말은 공동체의 방향이 되고, 
태도는 기준이 되며, 품격은 전체 분위기를 형성한다. 
설혜심 교수는 그의 저서 <매너의 역사>에서 
중세 프랑스 궁정문화를 논하면서 
지도자의 말투, 식사 예절까지도 
권위의 상징이었다고 말한다.
```

### 전개부 2: 보편적 원리/성경적 기초

**소제목 패턴:**
- "[가치]는 [방식]에서 비롯된다"
- 예: "품격은 단시간에 형성되지 않는다"

**내용 구조:**
```
[보편적 원리 제시].
특히 [기독교적 맥락].
예수 그리스도께서는 [사례].
그러기에 [적용점].
```

**예시:**
```
## 품격은 단시간에 형성되지 않는다

품격은 오랜 시간 훈련된 절제력, 일관된 언행, 
성찰된 인격에서 비롯된다.
특히 그리스도인 지도자에게 요구되는 품격은 
세상의 기준보다 훨씬 높아야 한다.
예수 그리스도께서는 하늘 권세를 가지셨음에도 
낮은 자를 존중하고 제자들의 발을 씻기셨다.
```

### 전개부 3: 현실 진단

**소제목 패턴:**
- "[상황]에서 더 절실해지는 [가치]"
- 예: "총회 앞두고 더 절실해지는 품격"

**내용 구조:**
```
[구체적 시점/상황].
[문제의식 제기].
[실천 주체]에게 [요청].
```

**예시:**
```
## 총회 앞두고 더 절실해지는 품격

제110회 교단 총회가 3개월 앞으로 다가왔다.
총회장을 비롯해 임원과 상비부, 위원회 등 
많은 일꾼들이 세워질 것이다.
총대들은 성숙하고 품격 있는 총회를 위해
품격 있는 지도자를 세운다는 
스스로의 기준을 세워가야 한다.
```

### 전개부 4: 대안 제시

**소제목 패턴:**
- "[주체]가 [대상]을 [동사]한다"
- 예: "품격 있는 지도자가 세상을 바꾼다"

**내용 구조:**
```
[주체]는 [행동]해야 한다.
그보다 더 중요한 것은 [본질].
[실천적 제안].
```

**예시:**
```
## 품격 있는 지도자가 세상을 바꾼다

총회의 얼굴은 총회장이며, 
교단의 신뢰는 지도자들의 언어와 태도에서 평가된다.
탁월한 정치력을 가진 지도자를 구해야 하지만, 
그보다 더 중요한 것은 
'삶이 아멘이 되어 향기 나는 지도자'를 
하나님 앞에서 겸손히 구하는 것이다.
```

## 결론부 작성법

### 패턴 1: 역사와 연결
```
[역사적 사례]처럼, 
오늘의 [주체] 역시 [행동]해야 한다.
결국 [핵심 가치]는 [결과]의 열쇠다.
```

### 패턴 2: 비전 제시
```
우리가 [실천]한다면, 
[긍정적 결과]가 일어날 것이다.
[희망의 메시지].
```

### 패턴 3: 본질 회귀
```
[주체]에게는 '[본질적 정체성]'이라는 
본질적 요청이 있다.
우리가 [본질]을 회복한다면, 
[희망적 미래].
```

## 논리 전개 기법

### 1. 삼단논법 활용
```
대전제: [보편적 원리]
소전제: [특수한 상황]
결론: [적용점]

예:
대전제: 지도자의 품격이 공동체를 결정한다
소전제: 교단 지도자는 하나님 나라를 대리한다
결론: 교단 지도자는 더 높은 품격이 요구된다
```

### 2. 대조와 대구
```
[A]는 [결과1]을 가져오지만,
[B]는 [결과2]를 가져온다.

예:
품격 없는 지도자는 공동체를 불안하게 하지만,
품격 있는 지도자는 공동체에 신뢰를 심어준다.
```

### 3. 점층적 강조
```
[A]뿐 아니라, [B]도, 심지어 [C]까지도

예:
지도자의 품격은 공동체의 신뢰 기반이며,
정치와 외교, 교육과 문화,
심지어 신앙의 깊이까지도 그 품격에 의해 결정된다.
```

## 근거 제시 양식

### 학술서 인용
```
[저자명] 교수는 그의 저서 <책 제목>에서 
[핵심 내용]고 말한다.

예:
설혜심 교수는 그의 저서 <매너의 역사>에서
중세 프랑스 궁정문화를 논한다.
```

### 역사적 사례
```
[시대] [지역]에서 [주체]는 [행동]했다.
이는 [의미/교훈]을 보여준다.

예:
중세 유럽 사회에서 귀족들은 
혈통만이 아니라 매너와 교양으로 
지위를 유지했다.
```

### 성경적 원리
```
예수 그리스도께서는 [행동/가르침]하셨다.
이는 [현대적 적용]을 보여준다.

예:
예수 그리스도께서는 제자들의 발을 씻기는 
섬김으로 본을 보이셨다.
이는 진정한 리더십이 섬김임을 보여준다.
```

## 문장 구성 패턴

### 정의 문장
```
[개념]이란 [정의]이다.
말하자면, [부연 설명].
```

### 원인-결과 문장
```
[원인] 때문에 [결과]가 발생한다.
그러므로 [결론].
```

### 대비 문장
```
[A]가 [속성1]이라면, [B]는 [속성2]이다.
[A]는 [결과1]을, [B]는 [결과2]를 가져온다.
```

### 강조 문장
```
무엇보다 [강조 내용].
특히 [세부 강조].
```

## 체크리스트

작성 후 다음 항목을 확인하세요:

### 구조
- [ ] 제목이 주장을 명확히 담고 있는가?
- [ ] 도입부에서 핵심 개념을 정의했는가?
- [ ] 각 섹션마다 소제목이 있는가?
- [ ] 역사적 사례나 학술적 근거를 제시했는가?
- [ ] 현실 진단이 시의성 있는가?
- [ ] 구체적 대안을 제시했는가?
- [ ] 결론이 희망적 비전을 담고 있는가?

### 논리
- [ ] 주장이 일관되게 전개되는가?
- [ ] 근거가 타당하고 충분한가?
- [ ] 논리적 비약이 없는가?
- [ ] 전제와 결론이 연결되는가?

### 문체
- [ ] 명료하고 간결한 문장인가?
- [ ] 단정적 어조를 유지했는가?
- [ ] 불필요한 수식어를 제거했는가?
- [ ] 감성적 표현을 절제했는가?

### 근거
- [ ] 학술서 인용이 정확한가?
- [ ] 역사적 사례가 구체적인가?
- [ ] 성경적 원리가 적절히 제시되었는가?

### 분량
- [ ] 전체가 1,500-2,000자인가?
- [ ] 각 부분이 균형있게 배분되었는가?

### 메시지
- [ ] 핵심 주장이 명확한가?
- [ ] 실천 가능한 대안이 있는가?
- [ ] 독자에게 동기를 부여하는가?
