# 이승호 목사 논단 스타일 가이드

이승호 목사님의 논단에서 나타나는 고유한 글쓰기 특징을 분석하여, 동일한 스타일로 논단을 작성할 수 있도록 정리한 가이드입니다.

## 핵심 스타일 특징

### 1. 명료하고 절제된 문체
- **짧은 문장**: 복잡한 문장 구조를 피하고 명료하게
- **직접적 표현**: 은유나 비유보다 직설적 서술 선호
- **단정적 어조**: "~이다", "~해야 한다" 명확한 주장

### 2. 체계적 논리 구조
- **정의 → 역사 → 원리 → 현실 → 대안** 순서
- 각 단계가 명확히 구분됨
- 소제목으로 논리적 흐름 표시

### 3. 권위 있는 근거 활용
- 학술서 구체적 인용
- 역사적 사례로 보편성 확보
- 성경적 원리로 정당성 확보

### 4. 균형잡힌 시각
- 비판보다 대안 제시
- 공격적 어조 배제
- 건설적 방향 제시

## 문장 패턴 분석

### 정의 문장
```
'[개념]'이란 단어는 사전적으로 '[정의]'로 정의된다.
말하자면, [구체적 설명].
[비유적 표현].
```

**실제 예시:**
```
'품격'이란 단어는 사전적으로 
'사람이 지니고 있는 품위나 인격의 수준'으로 정의된다.
말하자면, 그 사람의 겉모습이 아니라 
말과 행동, 태도 속에서 드러나는 됨됨이요, 
삶에서 품어내는 향기다.
```

**특징:**
- 사전적 정의로 권위 확보
- "말하자면"으로 일상적 언어로 재해석
- 은유 ("향기")로 마무리하되 절제적

### 역사적 사례 문장
```
[시대] [지역] [사회]에서 [개념]은 [의미/기능]였다.
[구체적 사례].
[학자] 교수는 그의 저서 <책 제목>에서 [내용]고 말한다.
```

**실제 예시:**
```
중세 유럽 사회에서 품격은 
단순한 도덕적 개념을 넘어 
지배계층이 가져야 할 도(道)의 기준이었다.
프랑스나 영국의 귀족들은 혈통만으로 귀족 대접을 받은 것이 아니라, 
매너와 교양, 책임 있는 태도를 통해 그 지위를 유지하며, 
스스로 명예롭게 여겼다.
설혜심 교수는 그의 저서 <매너의 역사>에서 
중세 프랑스 궁정문화와 18세기 영국 신사계급의 
생활방식을 논하면서 
지도자의 말투, 식사 예절, 걷는 자세까지도 
교양과 권위의 상징이었다고 말한다.
```

**특징:**
- 시대와 장소 명확히 명시
- 추상적 개념을 구체적 사례로 설명
- 학술적 인용으로 신뢰성 강화

### 보편적 원리 문장
```
어느 시대나 [보편적 진리].
[주체]의 [속성]은 [결과]가 되고, 
[속성2]는 [결과2]가 되며, 
[속성3]는 [결과3]를 형성한다.
```

**실제 예시:**
```
어느 시대나 지도자의 말은 공동체의 방향이 되고, 
태도는 기준이 되며, 
품격은 전체 분위기를 형성한다.
```

**특징:**
- "어느 시대나"로 보편성 강조
- 삼중 구조 (대구법) 사용
- 리듬감 있는 문장 구성

### 대비 문장
```
[부정적 주체]는 [부정적 결과]지만, 
[긍정적 주체]는 [긍정적 결과]다.
```

**실제 예시:**
```
품격 없는 지도자는 공동체를 불안하게 하지만, 
품격 있는 지도자는 공동체에 신뢰와 안정감을 심어주었다.
```

**특징:**
- 대조를 통해 메시지 강조
- 균형잡힌 구조
- 역사적 사실로 뒷받침

### 강조 문장
```
특히 [강조 대상]은 [내용].
그러기에 [결론].
무엇보다 [최우선 가치].
```

**실제 예시:**
```
특히 한 나라의 대통령이 국가를 대표하듯, 
교회나 교단의 지도자는 하나님 나라를 대리하는 상징이다.
그러기에 교회 지도자는 말과 행동에서 신중해야 하며, 
무엇보다 경건함과 절제함이 드러나야 한다.
```

**특징:**
- "특히"로 중요성 강조
- "그러기에"로 논리적 연결
- "무엇보다"로 우선순위 제시

### 부정 문장
```
[주체]는 [시간]에 [동사]지 않는다.
[이유나 설명].
[대신에 필요한 것].
```

**실제 예시:**
```
지도자의 품격은 하루아침에 만들어지지 않는다.
뛰어난 학벌이나 화려한 경력만으로 대신할 수도 없다.
품격은 오랜 시간 훈련된 절제력, 일관된 언행, 
성찰된 인격에서 비롯되며, 
내면의 신념과 도덕성이 쌓인 결과물이다.
```

**특징:**
- 부정으로 시작하여 주의 환기
- 잘못된 믿음 교정
- 올바른 이해로 전환

### 비유 문장
```
[A]가 [역할]하듯, [B]도 [역할]한다.
```

**실제 예시:**
```
한 나라의 대통령이 국가를 대표하듯, 
교회나 교단의 지도자는 하나님 나라를 대리하는 상징이다.
```

**특징:**
- 세속 → 신앙으로 연결
- 이해하기 쉬운 비유
- 책임의 무게 전달

### 성경적 근거 문장
```
예수 그리스도께서는 [상황]에도 불구하고 [행동]하셨다.
[구체적 사례].
```

**실제 예시:**
```
예수 그리스도께서는 하늘 권세와 지혜를 가지고 계심에도 불구하고 
결코 거만하거나 무례하지 않으셨다.
낮은 자를 존중하고, 제자들의 발을 씻기는 섬김으로 본을 보이셨다.
```

**특징:**
- 예수님의 본을 최고 기준으로
- 권세와 섬김의 대조
- 구체적 행동 예시

### 현실 진단 문장
```
[구체적 시점/상황].
[문제나 과제 제시].
```

**실제 예시:**
```
제110회 교단 총회가 3개월 앞으로 다가왔다.
총회장을 비롯해 임원과 상비부, 위원회 등 많은 일꾼들이 세워질 것이다.
```

**특징:**
- 구체적 시점 명시
- 객관적 사실 진술
- 시의성 부여

### 촉구 문장
```
[주체]는 [행동]에 자유로우며, 
[목적]을 위해 [실천]하자.
```

**실제 예시:**
```
총대들은 지역주의, 동기회, 그 외 아름답지 못한 행위들에 자유로우며, 
성숙하고 품격 있는 총회를 위해 
품격 있는 지도자를 세운다는 
스스로의 기준을 세워가자.
```

**특징:**
- 구체적 장애물 언급
- 명확한 목표 제시
- "~하자" 공동체적 호소

### 대안 제시 문장
```
[일반적 요구]를 해야 하지만, 
그보다 더 중요한 것은 [본질적 요구]다.
```

**실제 예시:**
```
탁월한 정치력을 가진 지도자를 구해야 하지만, 
그보다 더 중요한 것은 
'삶이 아멘이 되어 향기 나는 지도자'를 
하나님 앞에서 겸손히 구하자.
```

**특징:**
- 세속적 기준 인정
- "그보다 더"로 우선순위 전환
- 신앙적 가치 강조

### 결론 문장
```
결국 [핵심 가치]는 [결과]의 열쇠다.
우리가 [실천]한다면, [희망적 미래].
```

**실제 예시:**
```
결국 지도자의 품격은 시대의 윤리를 결정짓는 핵심이며, 
공동체의 미래를 열어가는 열쇠다.
우리가 예수님의 인격을 닮아 품격을 회복한다면, 
세상은 교회를 향해 다시 시선을 돌릴 것이다.
```

**특징:**
- "결국"으로 결론 명확히
- 핵심 메시지 재강조
- 희망적 비전 제시

## 소제목 작성 패턴

### 패턴 1: 주어-서술어 명제
```
[주체]는 [결과/속성]이다

실제 예시:
- "지도자 태도는 공동체의 기준이다"
```

### 패턴 2: 부정 명제
```
[주체]는 [시간/조건]에 [동사]지 않는다

실제 예시:
- "품격은 단시간에 형성되지 않는다"
```

### 패턴 3: 시간/상황 강조
```
[상황] 더 절실해지는 [가치]

실제 예시:
- "총회 앞두고 더 절실해지는 품격"
```

### 패턴 4: 주체-동사-목적어
```
[주체]가 [목적어]를 [동사]한다

실제 예시:
- "품격 있는 지도자가 세상을 바꾼다"
```

## 접속어 사용법

### 논리적 연결
- **그러기에**: 앞 내용의 당연한 결과
- **그래서**: 원인-결과 연결
- **결국**: 최종 결론 도출
- **특히**: 강조할 내용 제시

### 대비/전환
- **그러나**: 대조되는 내용
- **하지만**: 예외나 한계 제시
- **그보다**: 우선순위 전환

### 추가/강조
- **무엇보다**: 최우선 강조
- **특히**: 세부 강조
- **더욱이**: 추가 강조

## 표현 선호도

### 선호하는 표현
- "말하자면" (재해석)
- "그러기에" (결론)
- "어느 시대나" (보편성)
- "~에도 불구하고" (대조)
- "결국" (최종 결론)
- "우리가 ~한다면" (조건부 희망)

### 피하는 표현
- 과도한 감정 표현
- 복잡한 수사법
- 긴 종속절
- 애매한 주장

## 논리 전개 방식

### 1단계: 개념의 보편성 확립
```
정의 (사전) → 역사적 의미 → 보편적 가치
```

### 2단계: 특수성으로 좁히기
```
일반 사회 → 기독교 공동체 → 교단/교회
```

### 3단계: 시의성 부여
```
보편적 원리 → 현재 상황 → 긴급한 과제
```

### 4단계: 실천 촉구
```
일반적 기준 → 본질적 기준 → 구체적 실천
```

## 실전 작성 순서

### 1. 제목 정하기
- 핵심 주장을 명제형으로
- 인과관계나 당위성 표현

### 2. 소제목 구성
- 4-5개 소제목 미리 작성
- 논리적 흐름 확인

### 3. 각 섹션 작성
- 소제목 → 내용 순서
- 각 섹션당 300-400자

### 4. 도입부와 결론 마지막 작성
- 전체 맥락 파악 후 작성
- 순환 구조 확인

### 5. 퇴고
- 긴 문장 나누기
- 불필요한 수식어 삭제
- 논리적 연결 확인

## 문체 체크리스트

작성한 논단이 이승호 목사 스타일에 부합하는지 확인:

- [ ] 각 문장이 명료하고 간결한가?
- [ ] "~이다", "~해야 한다" 단정적 어조인가?
- [ ] 학술서나 역사적 사례를 인용했는가?
- [ ] 소제목이 명제형으로 되어 있는가?
- [ ] "어느 시대나", "특히", "그러기에" 등 특징적 접속어를 사용했는가?
- [ ] 세속적 기준 → 신앙적 기준으로 전환했는가?
- [ ] 대구법을 적절히 활용했는가?
- [ ] 감정적 표현을 절제했는가?
- [ ] 결론에서 희망적 비전을 제시했는가?
- [ ] 전체적으로 균형잡힌 논조를 유지했는가?
